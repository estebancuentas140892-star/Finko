# Identidad de Finko

Carpeta reservada para la marca propia: isotipo, logotipo (wordmark) y sus
variantes. Se llama `identidad/` y no `marca/` para no chocar con el vocabulario
del código, donde `MARCAS` significa marcas de terceros (ADR 025).

Estado actual:

- La marca visible hoy es el 💚 (sidebar, onboarding), decisión ADR 025 D6.
- El favicon vive en `assets/icons/favicon.svg` y los íconos PWA (192/512/maskable)
  en `assets/icons/`, generados por `scripts/gen-icons.py`.

Cuando se diseñe el isotipo definitivo, entra aquí primero (fuente vectorial),
y de aquí se derivan favicon e íconos PWA. Nomenclatura sugerida: `isotipo.svg`,
`wordmark.svg`, `isotipo-monocromo.svg`.
