# AGENTS.md

Las instrucciones para asistentes de IA en este proyecto viven en [CLAUDE.md](CLAUDE.md): workflow obligatorio, reglas innegociables del ADN, convenciones de código y estilo de escritura.

Este archivo existe solo para las herramientas que buscan `AGENTS.md` por convención, y a propósito no duplica ese contenido. Hasta el 2026-07-24 fue una copia completa de CLAUDE.md: llevaba 18 días desincronizada y le faltaba la matriz de decisión de modelo, así que cualquier herramienta que lo leyera trabajaba con reglas viejas. Una sola fuente de norma.
